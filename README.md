## About Me

I am a Mobile Engineer with **3+ years of experience** building and modernizing production Android applications.

My experience includes migrating legacy Java/XML applications to Kotlin and Jetpack Compose, designing multi-module architectures, and developing offline-first and real-time features for applications serving more than **10 million users**.

Some of my engineering highlights include:

* Migrating legacy Android codebases from Java/XML to Kotlin and Jetpack Compose
* Building an offline-first, real-time chat system supporting text and voice messages
* Designing reliable background synchronization and retry mechanisms
* Developing an AI-powered cheque extraction workflow that reduced manual data entry by **80%**
* Reducing an application's APK size from **48 MB to 18 MB**
* Building Android and Kotlin Multiplatform applications using Clean Architecture
* Integrating Google, Huawei, Firebase, REST, GraphQL, and third-party services
